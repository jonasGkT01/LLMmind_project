# AI usage

> *Written with AI assistance (Claude Code). This file is the AI attribution of the project.*

Much of this project's code and documentation was written or edited with AI coding assistants,
through Claude Code (Anthropic), at the developer's request. This page records how, and which
files were affected, so that the individual files do not each carry their own provenance block.

## Policy

- **Tool and models.** Claude Code (Anthropic), in the VS Code extension. Models: Claude Sonnet 5
  (`claude-sonnet-5`) until 2026-09-22, Claude Opus 5.5 (`claude-opus-5-5`) from 2026-09-23.
- **How AI-edited files are marked.**
  - Documentation files carry one line under their title: *Written with AI assistance (Claude
    Code)*, linking here.
  - Code files (Python, Bash, Snakefiles, YAML config) carry a two-line header comment: written or
    edited with AI assistance, the model, and the date of the latest AI edit.
  - The table below lists every such file with the date and model of its latest AI edit.
- **What changed and why** is in the daily changelogs, [`changelog/developers/`](changelog/developers/)
  and [`changelog/users/`](changelog/users/): each change records the request that led to it and the
  files it touched.
- **Review.** AI-written content is checked by the developer. The last column of the table says
  whether a file has been reviewed since its latest AI edit; it changes only when the developer
  says so.
